## Install

1. Download the ZIP and extract it to a permanent folder.
2. Open `chrome://extensions` in Chrome and enable Developer mode.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Open the extension and choose **Quick setup**. Sign in to Passive Income Rentals, choose your organization, and click **Connect**.
5. Sign in to Turo when prompted. Keep Chrome running and remain signed in to Turo for automatic syncing every five minutes.

The extension connects to `https://next.passiveincomerentals.com`. Quick setup creates and saves the organization connection token in the browser. The **Advanced** section also supports pasting an organization integration token manually.

For an existing unpacked installation, replace its files with the new package and click **Reload** on `chrome://extensions` to retain the same browser installation and saved settings.

Each release includes a versioned ZIP, the stable `TuroCommandCenter.zip` asset, SHA-256 checksums, and an installation guide. Use the **latest** links above when sharing with clients. This repository contains distribution materials only.
